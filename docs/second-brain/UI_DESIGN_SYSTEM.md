# JMH Connect — UI Design System

## 1. Design Direction
Product: JMH Connect
Style: Classical Elegance + Premium UI

The interface should feel calm, welcoming, trustworthy, spiritual, modern and professional.
Avoid excessive decoration, oversized gradients and unnecessary animation.
Prioritize readability, accessibility and simple workflows.

## 2. Approved Accent Color Palette
Use only these four approved accent colors:

- Primary Slate Indigo: #464B71
- Secondary Ocean Blue: #118AB2
- Accent Mint Teal: #7CD5C7
- Background Warm Ivory: #F2F2ED

Rules:
- Do not introduce additional accent colors without approval.
- Neutral white, grey, charcoal and suitable text colors may be used for surfaces, borders and readability.
- Check contrast before using accent colors for text.
- Use mint teal carefully when contrast is insufficient for small text.
- Do not use color alone to communicate status.

## 3. Typography
- Use a clean, readable modern sans-serif font.
- Establish a clear hierarchy for page titles, section headings, body text and supporting labels.
- Keep body text comfortable to read on mobile and desktop.
- Use consistent font weights and line heights.
- Avoid decorative fonts for functional content.

## 4. Layout and Spacing
- Use a consistent spacing scale.
- Align cards, forms, tables and page sections carefully.
- Prefer balanced whitespace over crowded layouts.
- Use consistent content widths and page margins.
- Make important actions visually clear.
- Avoid unnecessary nested cards and borders.

## 5. Components
Create reusable components when they provide genuine value.

Maintain consistent styles for:
- Buttons and links
- Form fields and validation messages
- Cards and dashboard summaries
- Tables and lists
- Dialogs and confirmation prompts
- Navigation and page headers
- Empty, loading, success and error states
- Attendance and duty status indicators

Use clear labels and helpful validation messages.
Confirm before destructive actions.

## 6. Surface Treatment
- Use refined borders and subtle shadows.
- Apply rounded corners consistently.
- Use glass effects only when they improve the design.
- Keep content surfaces readable against the warm ivory background.
- Avoid excessive blur, glow and shadow effects.

## 7. Responsive Design
- Support mobile, tablet and desktop layouts.
- Prevent horizontal overflow.
- Use mobile-friendly forms and touch targets.
- Adapt tables to smaller screens using an appropriate responsive pattern.
- Keep navigation and primary actions easy to find.

## 8. Accessibility
- Use semantic HTML and accessible Angular templates.
- Provide labels for inputs.
- Support keyboard navigation and visible focus states.
- Maintain sufficient text contrast.
- Provide accessible names for icon-only buttons.
- Communicate errors in text as well as visually.
- Respect reduced-motion preferences.

## 9. Product Experience
- Keep common member tasks simple and discoverable.
- Show useful empty states when no records exist.
- Display loading and error feedback honestly.
- Avoid unnecessary steps in attendance and duty workflows.
- Keep private information visible only to authorized users.
- Use consistent date and time presentation for Sri Lanka.

## 10. Angular Implementation Rules
- Inspect the existing Angular version, component structure and styling approach first.
- Follow existing project conventions unless an approved change is necessary.
- Reuse existing components and styles where practical.
- Avoid adding UI libraries without explaining the benefit and getting approval.
- Do not replace the existing design architecture unnecessarily.

## 11. Design Review Checklist
Before marking a UI task complete, check:
- Approved palette is respected.
- Layout is responsive.
- Typography and spacing are consistent.
- Forms have labels and validation feedback.
- Loading, empty and error states are considered.
- Keyboard focus and contrast are reasonable.
- No unrelated screens or components were changed.
